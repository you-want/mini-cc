## 技能工作原理

1. **技能定义**：每个技能包含详细的提示词（prompt）
2. **技能激活**：用户使用 `/skill <name>` 激活技能
3. **提示词注入**：技能的 prompt 注入到对话上下文
4. **AI 执行**：AI 按照技能提示词的指引工作
5. **工具调用**：AI 自动调用相关工具完成任务

## 扩展性

### 添加新的内置技能

1. 在 `src/skills/built-in/` 创建新文件
2. 导出符合 Skill 接口的对象
3. 重新编译，自动加载

### 用户自定义技能

用户可以在 `~/.mini-cc/skills/` 目录创建 JSON 文件：

```json
{
  "name": "my-skill",
  "displayName": "我的技能",
  "description": "自定义技能描述",
  "category": "custom",
  "prompt": "详细的提示词...",
  "examples": ["使用示例"],
  "tags": ["标签1", "标签2"]
}
```
